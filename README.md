# Food Delivery & Order Management System

A real-world food delivery application built for practicing:

- Java
- Spring Boot
- Angular
- MySQL
- Microservices
- Apache Kafka
- RabbitMQ
- REST APIs
- JWT Authentication
- JUnit & Mockito

## Project Structure

- backend - Spring Boot microservices
- frontend - Angular application
- database - SQL scripts
- docs - Project documentation

## Planned Microservices

1. User Service
2. Restaurant Service
3. Order Service
4. Payment Service
5. Delivery Service
6. Notification Service
